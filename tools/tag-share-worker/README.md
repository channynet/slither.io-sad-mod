# Slither Native 태그 공유·클라이언트 관리 서버

같은 클라이언트(Slither Native)를 쓰는 사람끼리 비밀번호 태그(내 화면에만 쓰는 것 포함)와 직접 추가한 이미지 태그를
서로 볼 수 있게 해 주는 Cloudflare Worker입니다. 무료 플랜으로 돌아갑니다.

## 배포 (한 번만)

1. Node.js가 있어야 합니다.
2. 이 폴더의 `deploy.cmd`를 더블클릭합니다(Cloudflare 로그인 → 배포). 직접 하려면 이 폴더에서:
   ```
   npx wrangler login
   npx wrangler deploy
   ```
3. 마지막에 나오는 주소(`https://slither-tag-share.<계정>.workers.dev`)를 클라이언트의
   태그 설정 → "태그 공유 서버"에 넣습니다.

## 클라이언트 접속 관리

0.101부터 클라이언트는 게임 접속 전에 `POST /v1/access`로 사용 허용 여부를 확인합니다.
게임 중에는 60초마다 다시 확인합니다. 태그 공유를 꺼도 이 기능은 작동합니다.
관리자가 차단한 IP 주소에는 HTTP 403과 `{"allowed":false}`를 보냅니다.
클라이언트는 게임 접속을 거절합니다. 게임 중이면 연결을 종료합니다.
관리 서버에 연결되지 않거나 서버의 응답이 올바르지 않으면 게임 접속을 허용합니다.

관리자 화면은 배포 주소의 `/admin`입니다. 관리자 화면에 접속하려면 별도의 관리자 키가 필요합니다.
관리자 키는 실행 파일·소스·URL에 넣지 않습니다. 브라우저는 관리자 키를 메모리에만 보관합니다.

1. 관리자는 `npx wrangler secret put ADMIN_TOKEN`으로 충분히 긴 임의의 관리자 키를 설정합니다. 키는 32자 이상이어야 합니다.
2. 관리자는 기존 배포 절차로 Worker를 배포합니다. `Access` SQLite Durable Object가 자동 추가됩니다.
3. 관리자는 `/admin`에서 관리자 키를 입력합니다.
4. 관리자는 접속 IP 주소·추정 국가·시도·도시·우편번호·위도·경도·시간대·통신망 운영기관·앱 버전·최근 접속 시각을 확인합니다.
5. 관리자는 각 항목의 **차단** 또는 **차단 해제**를 누릅니다. IP 주소를 직접 입력할 수도 있습니다.

개발 PC에 관리자 키가 Windows 계정으로 암호화되어 저장된 경우, 저장소의 `클라이언트 관리.cmd`를 실행하면
관리자 화면을 엽니다. 이 도구는 복호화한 관리자 키를 클립보드에 복사합니다.
이 암호화 파일은 `%LOCALAPPDATA%/SlitherNativeManagement/admin-key.dpapi`에 있습니다.
관리자 키는 배포 ZIP에 포함하지 않습니다.

서버는 Cloudflare가 제공한 `CF-Connecting-IP`와 `request.cf`의 지역 정보를 사용합니다.
지역 필드는 `country`, `city`, `region`, `regionCode`, `postalCode`, `latitude`, `longitude`, `timezone`, `asOrganization`입니다.
추정 좌표와 우편번호는 실제 집이나 건물의 위치를 보장하지 않습니다. 통신망 운영기관은 접속자의 신원이 아닙니다.
제공되지 않은 값은 미확인으로 표시합니다. 잘못된 좌표는 저장하지 않습니다. 별도 유료 조회 서비스는 사용하지 않습니다.
기존 접속 기록과 차단 목록은 유지합니다. 상세 지역 정보는 다음 게임 접속 확인 때 갱신됩니다.
클라이언트가 본문에 적은 IP 주소나 위치는 사용하지 않습니다.
앱은 버전만 전송합니다. 서버는 접속 시각을 기록합니다.
기록은 IP 주소별 최근 값 하나입니다. 기록은 사용자 수나 설치 수를 뜻하지 않습니다.
같은 IP 주소를 공유하는 사용자는 함께 차단됩니다. IP 주소가 바뀌면 같은 사용자라도 차단이 적용되지 않을 수 있습니다.
구버전·수정된 클라이언트와 관리 서버에 대한 통신 차단은 이 제한을 우회할 수 있습니다.
이 기능은 공식 slither.io 게임 서버의 차단 권한을 제공하지 않습니다.

`wrangler.toml`의 `RETENTION_DAYS`는 최근 접속 기록의 보관 기간입니다. 기본값은 30일입니다.
관리자 조회 시 만료한 접속 기록을 삭제합니다. 매일 실행되는 알람도 만료한 접속 기록을 삭제합니다.
차단 IP 주소는 관리자가 차단을 해제할 때까지 별도 보관합니다.
Cloudflare의 저장소 복구용 백업에는 삭제 전 데이터가 추가로 남을 수 있습니다.
닉네임·채팅·키 입력·게임 좌표·기기의 위치 측정값은 이 관리 기능으로 수집하지 않습니다.
수집 항목과 보관 기간은 배포본의 README-KO.txt와 이 문서에 기재합니다. 시작만 하고 게임에 접속하지 않으면 이 관리 기능은 전송하지 않습니다.

## 저장하는 태그 자료

- 게임 서버 주소별로, 그 서버의 지렁이 번호와 그 지렁이가 쓰는 태그(12초 동안만, 메모리에만).
- 올라온 이미지 태그 그림(PNG, 120KB 이하, 내용의 해시가 이름).
- 태그 자료에는 닉네임·계정을 저장하지 않습니다. 접속 IP 주소의 보관은 위의 클라이언트 접속 관리에 따릅니다.
